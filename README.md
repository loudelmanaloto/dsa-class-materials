# DSA Class Materials: Programming Refresher

Welcome! This repository is for students of **Data Structures and Algorithms (DSA)** in the **BS Entertainment and Multimedia Computing (BSEMC)** program.

Before we start DSA, we need to warm up. It's normal if Programming 1 and 2 feel like a distant memory. These materials re-teach the basics (variables, loops, functions, lists, and the like) so you're ready for the real topics ahead.

## Pick your track

| If you are in... | Language | Start here |
|---|---|---|
| **Game Development** | Java | [`java_gamedev/java_refresher_guide_gamedev.md`](java_gamedev/java_refresher_guide_gamedev.md) |
| **Digital Animation Technology** | Python | [`python_refresher_guide_animation.md`](python_refresher_guide_animation.md) |

Examples in each guide are themed for your field: health, loot and tile maps for games, and frames, colors and keyframes for animation.

There is also a general Python guide, [`python_refresher_guide.md`](python_refresher_guide.md), with plain examples that aren't tied to either track.

## How to use these materials

1. **Read the guide for your track** from Part 0 (setup) onward.
2. **Type every example yourself.** Don't copy-paste. Run it, then change something and run it again. Breaking code on purpose is how you learn what it does.
3. **Try each "Your Turn"** before looking at any hint.
4. **Finish with the practice set** for your track. It checks your answers automatically.

## Practice sets

Download the zip for your track, unzip it, and open the folder in VS Code.

| Track | Download | How to check your work |
|---|---|---|
| Game Dev (Java) | [**java-practice-gamedev.zip**](downloads/java-practice-gamedev.zip) | `javac Practice.java Checker.java SortedScores.java`, then `java Checker` |
| Animation (Python) | [**python-practice-animation.zip**](downloads/python-practice-animation.zip) | `python test_practice_anim.py` |
| General (Python) | [**python-practice-general.zip**](downloads/python-practice-general.zip) | `python test_practice.py` |

> On GitHub, clicking a zip link opens a page with a **Download** (or "Download raw file") button. Click it to save the file.

Run these commands in a terminal **inside the unzipped folder**. Edit only the practice file (for example `Practice.java` or `practice_anim.py`). Problems you haven't started show as "not started", which is fine.

## What you need

- **Java track:** JDK 17 or newer (JDK 21 recommended)
- **Python tracks:** Python 3.10 or newer
- **Editor:** Visual Studio Code

Each guide's Part 0 walks you through installing these, including fixes for the common problems.

## Stuck?

Read the error message from the bottom up, `print()` (or `System.out.println()`) your values to see what's really happening, and ask your instructor in class.

Happy coding!
